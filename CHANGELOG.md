# История изменений

В этом файле описываются все значимые изменения TrisigmaSDK.

## [0.1.3] - 2026-09-16

### Изменено

- `logExposure(label:)` теперь сохраняет ограниченное количество событий в persistent store. При превышении 5500 событий в хранилище, остаётся только 5000 новейших событий. Данный threshold необходим для минимизации перезаписей в persistent store.
- Добавлено логирование ошибки в случае, когда одни и те же события не могут отправиться 5 раз подряд. При этом, события остаются в persistent store и будут доступны для отправки при следующем запуске приложения / инициализации SDK, если ещё не вытеснены лимитом в 5000-5500 событий.

## [0.1.2] - 2026-08-14

### Изменено

- `logExposure(label:)` теперь регистрирует exposure только тогда, когда конфиг экспериментов действительно содержит label переданного эксперимента – т.е. пользователь участвует в эксперименте
